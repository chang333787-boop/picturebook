# 분기(선택형) 이야기 제작 — 기존 교육용 도구 조사와 「가지」의 차별점 재정의

작성 2026-09-06 · 계기: 컨설팅에서 "분기 구조는 기존에도 있다"는 지적 vs "교육용엔 없다"는 인식 → 사실 확인

## 0. 결론
**"분기 구조" 자체는 새롭지 않다.** 교육 현장에서 이미 쓰이는 도구가 여럿 있다(아래 표). 따라서 보고서·발표에서 "분기 스토리 도구는 없었다"고 쓰면 반박당한다. 정확한 차별점은 **"초등 저학년이 코딩·하이퍼링크 없이 분기를 설계하고, 전체 구조를 한눈에 보며, 계획(나침반)→표현→고쳐쓰기→출판이 한 흐름으로 이어지고, AI 도움을 교사가 통제하며 단계별로 줄이는 한국어 창작 플랫폼"**이다. 즉 차별점은 *분기의 존재*가 아니라 *분기를 초등 창작 수업에 맞게 통합한 방식*이다.

## 1. 분기 제작이 가능한 기존 도구 (2026-09-06 확인)

| 도구 | 분기 구현 방식 | 대상·현장 | 한계(초등 창작 수업 관점) |
|---|---|---|---|
| **Twine** (오픈소스) | 하이퍼텍스트 문법(`[[링크]]`)으로 장면 연결. 분기 지도 자동 표시 | 중고생·대학 인문/게임 수업. 초등 4~6학년 적용 연구 사례 있음(교사가 만든 학습 스토리를 학생이 읽는 형태가 다수) | 영어 UI·문법 입력 필요, 그림·음성 없음, 학급/교사 관리 없음, AI 없음 |
| **Elementari** (K-12) | 코드 블록(이벤트·변수)으로 선택지 연결 | 미국 K-12 글쓰기+코딩 수업, COPPA/FERPA, 교사 출판 통제 | 코딩 도구로서의 분기(변수·논리), 영어, AI 삽화·글 비계 없음, 한국어 미지원 |
| **Book Creator** | 정식 기능 아님 — 페이지 내부 하이퍼링크로 CYOA 흉내(자사 블로그 사례) | 초등 전 학년 디지털 북 | 구조를 볼 화면이 없어 별도 그래픽 오거나이저 필요, 링크 관리 수동, 분기 검증 없음 |
| **Google Slides/Docs/Keynote** | 슬라이드 간 링크로 CYOA | 교사 워크숍·수업 아이디어로 흔함 | 창작 도구가 아님(구조 시각화·계획·AI·출판 없음) |
| **스플(SPLE)** (국내) | 선택형 웹소설 플랫폼, 스튜디오로 창작 가능 | 성인·청소년 독자 플랫폼 | 교육용 아님, 초등 부적합(연령·콘텐츠), 교사 관리 없음 |
| **MyStoryBot 등 AI 스토리북** | AI가 선택지 포함 동화를 생성 | 가정·소비자 | 아이가 구조를 설계하지 않음(AI가 생성), 교사 통제 없음 |
| **Gemini Storybook** | 분기 없음(선형 10쪽) | 18세+ 개인 계정 | 비교 대상 아님(앞 문서 참조) |

## 2. 그래서 「가지」의 차별점은 무엇인가 (수정된 주장)

| 관점 | 기존 분기 도구(Twine·Elementari·링크식 CYOA) | 가지 |
|---|---|---|
| 분기를 만드는 방법 | 문법 입력·코드 블록·수동 하이퍼링크 | 카드에 **행동 버튼**을 달고 다음 장면을 고르는 방식 — 글자만 쓰면 됨(초등 저학년 가능) |
| 전체 구조 조망 | Twine만 지도 제공(텍스트 노드), 나머지는 없음 | **이야기 길 보기**: 장면·선택·엔딩을 그림책 카드로 시각화, 끊어진 길·닿지 않는 장면 표시 |
| 계획 단계 | 없음(외부 오거나이저) | **생각 나침반**(9문항+후속 질문+가치 선택)이 분기 설계의 앞단 |
| 발달 단계 비계 | 단일 난이도 | **1·2단계는 일직선으로 잠그고**(분기 대신 이야기 흐름 학습), 3단계에서 분기 개방 — 학년·준비도에 따른 사다리 |
| 그림·표현 | 텍스트 중심(Twine) / 학생 그림(Book Creator) | 학생 원화 + AI 완성(교사 토글), 인물 일관 |
| AI의 자리 | 없음 또는 AI가 전부 생성 | 원본 보존·후보 비교·단계별 이양·서버 필터·교사 통제 |
| 수업 운영·출판 | 도구별 상이(Elementari 강함) | 학급 코드·모둠 계정·감상 링크·학급 책장·댓글·A4 인쇄가 한 흐름 |

## 3. 보고서 문장 교정 제안
- ❌ "기존 도구는 분기 구조 설계 기능이 제한적이다" (표 1 현행) → 반박 여지: Twine·Elementari가 있다.
- ✅ "분기 서사 제작 도구(Twine, Elementari 등)는 존재하나 문법·코드 입력이 필요하고 영어 기반이어서 초등 저학년 창작 수업에는 문턱이 높으며, 계획 도구·AI 비계·교사 운영과 분리되어 있다. 국내 초등용 도구는 순차형(Book Creator 류)이거나 AI 생성 중심(Gemini Storybook 류)이다. '가지'는 분기 설계의 문턱을 버튼 연결과 시각화로 낮추고, 준비도에 따라 분기를 잠그고 여는 3단계 비계 안에 계획·AI·운영·출판을 통합하였다."
- 표 1에 열 하나 추가: **"분기 도구 (예: Twine·Elementari)"** — 이야기 구조=분기(문법/코드), 계획 도구=없음, 글의 주체=학생, 그림=텍스트 중심/제한, 학생 계정=필요, 교사 AI 통제=해당 없음, 언어=영어.

## 5. 보고서 표 1 대체안 (5도구 통합)

| 비교 항목 | Book Creator (순차형 제작) | Gemini Storybook (AI 생성) | Twine (분기·하이퍼텍스트) | Elementari (분기·코딩) | **가지 branch** |
|---|---|---|---|---|---|
| 이야기 구조 | 선형 페이지(하이퍼링크로 분기 흉내 가능) | 선형 10쪽 고정 | 분기(문법 `[[링크]]`) | 분기(코드 블록·변수) | **버튼 연결로 분기**, 1·2단계 일직선 잠금 → 3단계 개방 |
| 분기 만드는 난이도 | 링크 수동 관리 | 해당 없음 | 문법·영어 | 코딩 | **글자만 쓰고 다음 장면 고르기(저학년 가능)** |
| 전체 구조 조망 | 없음(외부 오거나이저) | 없음 | 텍스트 노드 지도 | 없음 | **이야기 길 보기**(그림책 카드·끊긴 길 표시) |
| 계획 단계 | 템플릿·그래픽 오거나이저 | 없음(프롬프트 대화) | 없음 | 없음 | **생각 나침반** 9문항+후속 질문+가치 선택 |
| 글의 주체 | 학생 | AI 전부(페이지 편집 불가) | 학생 | 학생 | **단계별 이양**(1단계 AI → 3단계 학생), 원본 보존 |
| 그림 | 펜·이미지 검색·AutoDraw | AI 생성(스타일 선택) | 없음(텍스트 중심) | 캐릭터·애니메이션 에셋 | **학생 원화 + AI 완성**, 인물 시트로 전 장면 일관 |
| 발달 단계 비계 | 단일 | 단일 | 단일 | 학년별 레슨 | **1·2·3단계 사다리**(AI 도움이 줄어듦) |
| 학생 계정 | 필요 | 18세+ 개인 계정 | 불필요 | 필요 | **불필요** — 학급 코드·모둠 계정 |
| 교사의 AI 통제 | 해당 없음 | 없음 | 해당 없음 | 해당 없음 | **기능별 토글·사용량 상한·킬스위치** |
| 안전·개인정보 | 교사 모니터링 | 개인 계정 정책 | 없음 | COPPA·FERPA | **서버 경유·유해 표현 8유형 차단·개인정보 미전송** |
| 수업 운영·출판 | 학급 라이브러리·과제·QR·ePub | 공개 링크·인쇄 | 없음(HTML 파일) | 교사 출판 통제 | **학급 책장·댓글·감상 링크·A4 인쇄** |

읽는 법: 가로로는 분기(Twine·Elementari)·그림(Book Creator)·AI(Gemini)를 각각 잘하는 도구가 있지만, 세로로 가지 열만 계획→분기 설계→표현→AI 조력→운영·출판이 한 칸도 비지 않는다.
