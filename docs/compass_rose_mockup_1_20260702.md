## 1. 시안 구조 (rose audit 권장안 그대로)
- **중앙 원** = 💎 coreMessage(끝까지 지킬 중심) — 나침반 바늘 은유
- **4방위 카드** = N 주인공 / E 원하는 것 / S 어려움 / W 중요한 선택 (+점선 원·방위선·N/E/S/W 글자)
- **하단 시간띠** = 🛤 진엔딩까지 가는 기본 길: 시작→생기는 일→점점 어려워져요→중요한 선택→🏁진엔딩(5정거장 실선)
- **옆가지** = 🌿 다른 선택을 하면 — '중요한 선택' 정거장에서 점선 ㄴ자 분기(실패 아닌 "다른 길" 톤)
- 헤더(모둠/이름 손글씨 칸+기본 길이 배지) + 📝 학생 메모칸(빈 줄 3) + 참고자료 문구
- 기술: 선/원만 인라인 SVG, **텍스트는 HTML 카드**(줄바꿈·유지보수 쉬움). 팔레트 = thought-compass.css 톤.
