# 연구보고서 보충 — 유사 도구(Gemini Storybook · Book Creator)와의 차별점

## 0. 왜 보충이 필요한가
보고서 Ⅰ장 4절 「기존 도구와의 차별성」은 기존 도구를 **"순차형 제작 도구"와 "생성 중심 서비스"라는 두 유형**으로만 묶고(표 1), 실제 제품명을 하나도 들지 않는다. 본문 전체에서 `Gemini`·`Storybook`·`Book Creator`·`유사`·`선행` 검색 결과 0건. 심사위원이 가장 먼저 떠올릴 두 제품(구글 Gemini Storybook = 생성 중심, Book Creator = 순차형 제작)을 **이름을 들어 대조**하면 "무엇과 다른가"가 한 문단으로 분명해진다. 아래 사실은 2026-09-05 기준 공식 페이지에서 확인한 것만 적었다.

## 1. 사실 확인표 (출처는 §4)

| 항목 | Gemini Storybook (Google) | Book Creator | **가지 branch** |
|---|---|---|---|
| 한 줄 정의 | 한 문장 요청으로 **10쪽 그림책을 AI가 통째로 생성** | 학생이 글·그림·음성·영상을 넣어 **페이지를 차례로 만드는** 디지털 북 도구 | 학생이 **구조(선택·분기)를 설계**하고 AI는 준비도에 맞춰 표현만 돕는 창작 플랫폼 |
| 사용 주체·계정 | Gemini 앱 **18세 이상 개인 계정** 전용(Workspace·학생 계정은 공유 불가) | 전 연령, 교사가 학급 라이브러리 개설 | 학생 개인 계정 없음 — 학급 코드+모둠 계정(익명 인증), 교사만 로그인 |
| 이야기 구조 | 선형 10쪽 고정 | 선형(페이지 순서) | **선택지에 따라 갈라지는 분기** + 전체 연결을 보는 「이야기 길 보기」(1·2단계는 일직선 비계) |
| 계획 단계 | 없음(프롬프트 대화로 대체) | 없음(템플릿·그래픽 오거나이저 900+) | **생각 나침반** 9문항 + 후속 질문 + 「말하고 싶은 가치」 3택1 → 구조를 먼저 세움 |
| 글의 주도권 | AI가 전부 씀. 페이지 직접 편집 불가, "더 재밌게" 같은 재요청만 | 학생이 전부 씀(AI 문장 생성 없음) | 1단계 AI 완성문 → 2단계 AI 3장면+학생 이어쓰기 → 3단계 학생 전부. **원본과 AI 제안 분리 저장·학생이 비교 선택** |
| 그림 | AI 생성(수채화·클레이 등 스타일 선택), 사진·그림을 참고 입력 가능 | 펜 도구·AutoDraw·이미지 검색·배경 제거. 이야기 맥락을 아는 삽화 생성 없음 | 1단계: 글 기반 AI 생성 + **인물 외형 시트로 전 장면 일관** · 2·3단계: **학생 원화(구도)를 AI가 완성도만 높임**, 원화 보존 |
| 교사 운영 | 없음 | 강함: 학급 라이브러리·진도 모니터링·과제·루브릭·공동교사 | 학급 코드·모둠 계정·**AI 기능별 토글(글/그림/점검)**·사용량 총량·킬스위치·작품 잠금·인쇄물 메뉴 |
| 협업 | 없음 | 실시간 공동 편집 | 모둠 단위 1작품(단일 세션 인수) |
| 공유·출판 | 공개 링크·브라우저 인쇄 | 온라인 출판·QR·리믹스·PDF/ePub/영상 | 감상 링크·학급 책장·댓글·A4 그림책 인쇄(교사 경유) |
| 언어·교육과정 | 45+개 언어 낭독(일부만) | 100+개 언어 번역·130+ 접근성 기능 | 한국어 전용 UI·2022 개정 국어/미술/도덕 성취기준 연계 |
| 비용·설치 | 무료(Gemini 계정) | 무료 1라이브러리·40권·출판 10권, 유료 무제한 | 무료·설치 불필요·학생 AI 직접 접속 없음(서버 경유) |
| 안전·원본 | 개인 계정 정책(학생 부적합) | 교사 모니터링 | 서버 경유·콘텐츠 안전 스캔(키워드+모델 2층)·원본 보존·개인정보 최소(이름·PIN 없음) |

## 2. 한 문단으로 정리한 차별점 (Ⅰ장 4절 대체·보강용)

> 유사 도구는 크게 둘로 나뉜다. **Gemini Storybook**(구글)은 한 문장 요청으로 AI가 10쪽 그림책을 통째로 만들어 주는 '생성 중심' 서비스로, 결과는 빠르지만 학생이 이야기의 흐름과 인과를 스스로 계획하고 고쳐 가는 과정이 없고, 18세 이상 개인 계정에서만 쓸 수 있어 초등 교실에서 학생이 직접 쓸 수 없다. **Book Creator**는 학생이 글·그림·음성을 넣어 페이지를 차례로 만드는 '순차형 제작' 도구로 교사 운영과 협업이 탄탄하지만, 이야기가 선형이라 선택과 결과의 관계를 설계할 자리가 없고, AI는 검색·자동 그리기 보조에 머물러 이야기 맥락을 아는 삽화나 인물 일관성을 주지 않는다. '가지'는 두 유형의 빈자리를 겨냥한다. 첫째, 학생이 장면과 선택지를 잇는 **분기 구조**와 전체를 조망하는 「이야기 길 보기」로 서사를 설계한다. 둘째, **생각 나침반**으로 구조를 먼저 세운 뒤 AI가 준비도에 따라 글·그림의 몫을 **3단계로 줄여 가며** 돕고, AI 제안은 원본과 분리 저장되어 학생이 비교·선택한다. 셋째, 학생은 개인 계정 없이 학급 코드로 참여하고 AI는 서버를 거쳐 교사가 기능별로 켜고 끄므로, 초등 교실의 개인정보·안전 요건 안에서 생성형 AI를 쓸 수 있다.

## 3. 표 1에 추가할 행 제안
현재 (표 1)은 유형 2열이다. 열을 하나 더 두어 **제품명**을 적으면 심사위원의 대조가 쉬워진다.

| 비교 항목 | 순차형 제작 (예: Book Creator) | 생성 중심 (예: Gemini Storybook) | 가지 |
|---|---|---|---|
| 이야기 구조 | 선형 | 선형 10쪽 | **분기 + 이야기 길 보기** |
| 계획 도구 | 템플릿 | 없음 | **생각 나침반·가치 선택** |
| 글의 주체 | 학생 | AI | **단계별(AI→학생) 이양·원본 보존** |
| 그림의 주체 | 학생(AI 보조 없음) | AI | **학생 원화 기반 AI 완성·인물 시트 일관** |
| 학생 계정 | 필요 | 18세+ 개인 계정 | **불필요(학급 코드·모둠)** |
| 교사의 AI 통제 | 해당 없음 | 없음 | **기능별 토글·총량·킬스위치** |
