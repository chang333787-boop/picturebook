# DRAWING-STUDIO-2-SIMPLE — 직접 그리기 간단 모드 + 저장 안전장치

## 1. 간단 모드 정책 (기능 삭제 0 — 재배치만)
- **기본 노출(core)**: ✏️펜 · 🧽지우개 · 색 8+자유선택 · 굵기 4프리셋 · ↶되돌리기 · ↷다시 · [🧰 도구 더보기] (+저장/취소/✕는 기존 위치)
- **도구 더보기(adv·기본 접힘)**: 직선/사각/원 · 채우기 · 색따기 · 이동 · 줌 · 펜 종류 4 · 도형 채움 · 자유 굵기 슬라이더 · 투명도 · 펜 압력 · **전체 지우기**(실수 방지 위해 이동·confirm 기존 유지)
- 핸들러는 전부 클래스 기반이라 **로직 무변경** — DOM 배치만 core/adv 래퍼로 이동. 접기/펼치기 시 `_resizeCanvasDisplay()` 재계산.
- 상태 문구 1줄(`.pb-draw-status`): "지금은 ✏️ 펜으로 그리고 있어요." 등 8도구 매핑 — 고급 도구 선택 후 접어도 현재 모드가 항상 보임(이동 모드는 "(그려지지 않아요)" 명시).
- 선택 강조: `.pb-draw-tool.is-on` 크림 배경(대비 약) → **sage 채움+흰 글자**. core 버튼 40~42px+.

## 2. 저장 안전장치 3건
1. **busy 가드**: `state.isSaving` + 버튼 disabled·"저장 중...". ★구현 중 순서 버그 발견·수정 — busy를 빈 캔버스 confirm **이전**에 세움(confirm await 중 재클릭 재진입 차단·하니스 3연타 실측으로 검출). 실패 5경로(gate/업로드/commit/flush/catch) 전부 복구.
2. **저장 성공 안내**: 모달 닫힌 뒤 토스트 "✅ 그림을 저장했어요."(1.6s·pointer-events 없음).
3. **빈 캔버스 confirm**: "아직 그린 내용이 거의 없어요 / 이대로 저장할까요?" — 차단 아님. 판정=150×100 픽셀 샘플 nonWhite<12. ★1차 구현(60×40·0.3%)은 **가는 선 하나를 빈 캔버스로 오판**(실측 nonWhite 4) → 해상도/임계 보정 후 재검증. 기존 그림 이어 그리기는 배경이 캔버스에 그려져 픽셀 기준이라 오판 없음(실측 확인).
