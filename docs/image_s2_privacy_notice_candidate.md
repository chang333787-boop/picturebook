# imageS2 개인정보 안내 문구 — 후보(초안, 미공개)

> ⚠️ **문구 후보일 뿐, 실제 개인정보처리방침 공개본을 수정하지 않는다.** OpenAI(gpt-image-2) 사용을 가정한 초안.
> 최종 문구·법적 결론·공개는 운영자/법무/학교 협의 후. 조사일 2026-06-25 공식 정책 기준.

## 1. 안내(학생/보호자용) 문구 후보
> "선택한 그림을 더 또렷한 그림책 그림으로 바꾸기 위해, 그 그림이 외부 AI 이미지 서비스(OpenAI)로 전송될 수 있어요.
> 전송되는 것은 **선택한 그림 이미지와 변환 지시문**뿐이고, 이름·학번 등 다른 정보는 보내지 않아요.
> 변환은 **선생님이 실행**하며, 원본 그림은 그대로 보관돼요. 원하면 원본만 사용할 수 있어요."

## 2. 전송 항목 / 목적 / 제공자
| 항목 | 내용 |
|---|---|
| 전송 데이터 | 학생이 선택한 그림 이미지(PNG) + 고정 변환 프롬프트. (이름/학번/메타데이터 미전송, EXIF 제거 예정) |
| 목적 | 학생 그림의 보존형 발전(그림책풍 마감). 새 그림 생성 아님. |
| 실행 주체 | 교사(서버 측 호출). 학생이 직접 API 호출하지 않음. |
| 제공자 | OpenAI (`gpt-image-2`, `/v1/images/edits`) |

## 3. 보관 · 학습 사용(공식 정책, 2026-06-25)
- **학습 사용**: OpenAI API는 기본적으로 입력(이미지 포함)을 모델 학습에 **사용하지 않음**(opt-in 시에만 공유). 출처: openai.com/enterprise-privacy.
- **보관**: 남용 모니터링 로그 **최대 30일** 후 삭제(법적 요구 제외). **ZDR(Zero Data Retention)** 적용 시 보관 안 함(승인 필요).
- **미성년(중요)**: 초등학생은 대개 만 13세 미만 → OpenAI 정책상 **under-13 개인정보 처리 전 ZDR 적용 필요**(+COPPA safeguards). 출처: under-18 API guidance.

## 4. 국외 이전 / 데이터 레지던시
- OpenAI API는 글로벌. **한국 데이터 레지던시 opt-in**(eligible project) 가능. 기본 처리는 미국일 수 있음 → **국외 이전 동의/안내 검토 필요**.

## 5. 학교 · 보호자 안내 필요성
- 학생 그림(개인정보 소지 가능: 이름·얼굴·식별 단서)이 외부로 전송될 수 있으므로 **사전 안내·동의 절차** 검토 필요(학교/교육청 지침에 따름).
- 결과물 노출 범위(감상 공개)와 원본↔변환 선택권 안내.
