방법: 마크업/렌더러 정적 전수 조사(sceneRenderer.js·maker.html·ui.js). 실화면 스크린샷은

## 1. 전체 흐름 판정 — 골격은 이미 학생용으로 정비돼 있다
```
나침반(강제 게이트·v2 10문항) → 기본 장면 자동 생성(8/12/15) → 브랜치(카드 지도)
 → 카드 ✎(이 장면 다듬기) → 다듬기 화면(그림 그리기·본문) → 작품 마무리(3단계 카드)
 → ▶ 감상 테스트
```
각 단계의 "다음 행동"이 코드상 명확: 나침반 완료가 장면을 만들어 주고, 카드마다 ✎가 있고,
상단바에 ▶ 감상 테스트가 상시 노출. 이전 루프들(BRANCH-TOPBAR 다이어트·카드 지도형 재설계·
PANEL-CLEANUP·작품 마무리 그룹화)이 이미 큰 위계를 잡아 둠.

**핵심 발견**: `body.beginner-mode`가 이미 존재 — JSON 저장/불러오기/전체 초기화/줌/도움말/
범례가 `adv-only`로 **기본 숨김**(⚙️ 더보기 뒤). 즉 "브랜치 화면 간단 모드"는 사실상 구현돼
있어 C안(그림책 모드 대공사)의 필요 근거가 약함.

## 5. 태블릿/PC 사용성 (정적 판단 + NOT_VERIFIED)
