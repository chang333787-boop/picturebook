## 2. 출판형 페이지 설계 (권장)

- **용지: A4 세로(portrait)** — 책자 제본(스테이플/링) 표준·표지/지도와 방향 통일.
  그림은 감상 정본이 가로 3:2(drawingratio1)라 페이지 폭(690px) 기준 높이 ≈460px —
  세로 페이지 상단 절반을 그림이 크게 채우고 아래 글·선택지가 남는 구성이 자연스러움.
  (가로 용지는 그림이 ~15% 더 커지지만 제본·표지 방향 혼합 문제로 비권장)
- **장면 페이지 구성(위→아래)**:
  1. 머리: `N번 장면` 배지(+제목·엔딩/추가 장면 플래그) — 기존 head 재사용, 크기만 상향
  2. 그림: 페이지 폭 100%·max-height ≈55%(3:2면 꽉 참·세로 그림은 contain) — 크롭 금지(학생 그림 안 자름)
  3. 본문: 13.5~14pt·줄간 1.7·keep-all (현 11pt에서 상향)
  4. 하단 고정 선택지 박스: `▸ 선택지 글 … → N번 장면으로 가세요` (12pt·굵은 번호)
     / 선택지 없으면 `— 이야기 끝 —` 크게
- 그림 없는 장면: 본문을 세로 중앙에 크게(빈 그림 틀 미출력).
- 페이지 수: 표지 1 + 지도 1 + 장면 N → **20장면 = 22p** (양면 인쇄 시 11장).
- 흑백 가독성: 현 CSS가 이미 #111/#888 무채색 기준 — 유지. 그림만 컬러 권장 안내.

## 3. 구성안 비교

- **A안(추천): 기존 `🖨 그림책 인쇄` 버튼을 출판형으로 전환.**
  점검 용도는 이미 ①지도 페이지(유지) ②고쳐쓰기 자료 인쇄 ③화면의 이야기 길 보기가
  커버하므로 축소 2/page 양식을 따로 남길 실익이 없음. UI 변화 0(버튼 그대로)·코드 최소.
- B안(버튼 2개: 출판/지도): 지도는 출판형 안에 1p로 이미 포함 — 중복. 비권장.
- C안(옵션 모달): 유연하지만 지금 수요는 출판형 하나. 실사용 후 요구가 갈릴 때 재검토.
