# 가지(branch) 개인정보 처리방침 초안

> ⚠️ **이 문서는 초안(draft)입니다.**
> 실제 공개 전에 **법적 검토**와 **운영자 정보·보유 기간 등 [확정 필요] 항목 입력**이 반드시 필요합니다.
> 본 초안은 개인정보보호위원회의 「개인정보 처리방침 작성지침」 항목 구성을 참고해 작성되었습니다.

가지(branch)(이하 "서비스")는 초등학생과 교사가 수업에서 분기형 이야기·그림책·텍스트·무비형 작품을 만들고 감상하는 교육용 도구입니다. 서비스는 이용자의 개인정보를 소중히 다루며, 「개인정보 보호법」 등 관련 법령을 준수하기 위해 노력합니다. 이 처리방침은 학부모·교사도 쉽게 읽을 수 있도록 작성했습니다.

---

## 1. 개인정보 처리 목적

서비스는 다음 목적을 위해 개인정보를 처리합니다. 아래 목적 외의 용도로는 이용하지 않으며, 목적이 바뀌면 별도 동의를 받습니다.

- 교사 회원 가입·인증 및 학급 운영
- 학생·팀이 만든 작품(이야기·그림책·텍스트·무비형)의 저장·수정·감상 제공
- 학급/팀 관리 및 작품 공유
- AI 텍스트 정돈·발전 등 선택적 기능 제공
- 서비스 오류 대응, 보안 유지, 부정 이용 방지
- 서비스 개선 및 운영

## 2. 처리하는 개인정보 항목

서비스는 학생의 **실명을 필수로 수집하지 않으며**, 운영상 실명 대신 팀명·별칭 사용을 권장합니다.

### 2-1. 교사 관련
- 이메일 주소
- Firebase 인증 식별자(Auth UID)
- 학급 ID 및 학급 설정
- AI 사용 설정(기능 허용/차단 등)

### 2-2. 학생/팀 관련
- 팀명 또는 학생 계정명(실명 입력은 권장하지 않음)
- 로그인 PIN 또는 비밀번호
- 학급 ID
- 작품 데이터(장면 본문, 선택지·분기 구조 등)
- 업로드 이미지 또는 그림판으로 그린 이미지
- 작품 설정값
- 저장·수정 시각

### 2-3. 자동으로 수집되는 기술 정보
- 접속 기록
- 브라우저·기기 정보
- 오류 로그
- 브라우저 저장소(localStorage/sessionStorage)에 저장되는 편집 상태, 보기 모드(viewMode), 임시 세션 정보
- Firebase 인증·보안 로그

## 3. 개인정보 처리 및 보유 기간

- 개인정보는 원칙적으로 **학급 운영 기간 동안** 보관합니다.
- 교사 또는 운영자가 삭제를 요청하거나 학급·팀을 삭제하면 해당 데이터를 삭제합니다.
- 보안·장애 대응을 위한 백업 및 로그는 일정 기간 보관될 수 있습니다.
- 법령에서 별도 보존 의무를 정한 경우 해당 기간 동안 보관합니다.

> 📌 **[보유 기간 확정 필요]** — 구체적인 보관·파기 기간은 운영 정책 확정 시 명시합니다.

## 4. 개인정보의 제3자 제공

서비스는 이용자의 개인정보를 **원칙적으로 외부에 제공하지 않습니다.** 다만 다음의 경우에는 예외로 합니다.

- 이용자가 사전에 동의한 경우
- 법령에 근거가 있거나 수사기관 등이 적법한 절차에 따라 요청한 경우

(외부 서비스 이용에 따른 처리위탁은 아래 5항을 참고하십시오.)

## 5. 개인정보 처리 위탁 및 외부 서비스 이용

서비스는 안정적인 운영을 위해 아래 외부 서비스를 **이용할 수 있습니다.** 실제 이용 범위는 기능 활성화 단계에 따라 달라질 수 있습니다.

| 수탁자/서비스 | 이용 목적 |
|---|---|
| Google Firebase — Authentication | 교사 인증 |
| Google Firebase — Realtime Database | 학급·작품 데이터 저장 |
| Google Firebase — Cloud Storage | 이미지 등 파일 저장 |
| Google Firebase — Cloud Functions | 서버 처리(AI 호출 중계 등) |
| Google Firebase — Hosting 등 인프라 | 서비스 제공 |
| GitHub Pages 등 정적 호스팅 | 페이지 제공 |
| OpenAI, Google Gemini 등 AI API 제공업체 | AI 텍스트(및 향후 이미지) 기능 제공 |

> 📌 **[외부 AI 제공업체 확정 필요]** — 실제 사용하는 AI API 제공업체와 전송 데이터 범위는 해당 기능을 정식 제공할 때 명확히 고지합니다.

## 6. AI 기능과 개인정보

- AI 기능은 **선택적으로** 사용됩니다. 사용하지 않으면 관련 데이터는 AI API로 전송되지 않습니다.
- AI 텍스트 기능을 사용하면 작품 본문, 장면 정보, 선택지 등 처리에 필요한 내용이 **외부 AI API 제공업체로 전송될 수 있습니다.**
- 향후 AI 이미지 기능을 사용하면 업로드 이미지 또는 그림판 이미지가 **외부 AI API 제공업체로 전송될 수 있습니다.** (현재 이미지 AI는 보호 구조만 갖춘 준비 단계로, 일반 제공 전입니다.)
- AI 결과는 **원본 작품을 자동으로 덮어쓰지 않고, 후보로 제공하는 것을 원칙**으로 합니다.
- 이미지 AI 결과도 **원본 이미지(imageData/imageUrl)를 덮어쓰지 않는 구조**를 원칙으로 합니다.

## 7. 정보주체와 법정대리인의 권리·의무 및 행사 방법

- 이용자(및 만 14세 미만 아동의 법정대리인)는 언제든지 자신의 개인정보에 대해 **열람·정정·삭제·처리정지**를 요청할 수 있습니다.
- 초등학생 이용자의 경우, 권리 행사는 **교사 또는 법정대리인(보호자)을 통해** 이루어질 수 있습니다.
- 권리 행사는 아래 문의처를 통해 요청할 수 있으며, 서비스는 지체 없이 조치합니다.
- 이용자는 개인정보를 정확하게 유지할 의무가 있으며, 타인의 정보를 침해해서는 안 됩니다.

## 8. 개인정보 파기 절차 및 방법

- 보유 기간이 지나거나 처리 목적이 달성되면 해당 개인정보를 지체 없이 파기합니다.
- **전자적 파일**: 복구·재생되지 않도록 안전한 방법으로 삭제합니다.
- **백업·로그 등**: 보존 기간 경과 후 순차적으로 삭제합니다.
- 학급·팀 삭제 시 연결된 작품 데이터도 함께 삭제하는 것을 원칙으로 합니다.

## 9. 개인정보의 안전성 확보 조치

서비스는 개인정보 보호를 위해 다음과 같은 조치를 합니다.

- 접근 권한 관리(교사/학급 단위 권한 분리, 보안 규칙 적용)
- 인증을 통한 접근 통제(Firebase Authentication)
- 전송 구간 암호화(HTTPS)
- 데이터베이스·스토리지 보안 규칙 적용
- 오류·보안 로그 점검을 통한 이상 접근 대응

## 10. 쿠키 및 로컬 저장소 등 자동 수집 장치

- 서비스는 원활한 이용을 위해 브라우저의 **localStorage·sessionStorage**에 편집 상태, 보기 모드(viewMode), 임시 세션 정보 등을 저장할 수 있습니다.
- 인증·보안을 위해 쿠키 또는 유사 기술이 사용될 수 있습니다.
- 이용자는 브라우저 설정을 통해 저장을 거부하거나 삭제할 수 있으나, 이 경우 일부 기능 이용이 제한될 수 있습니다.
