### ★ B. 표 1 「기존 도구와 '가지'의 비교」 교체 (6쪽 Ⅰ.4) — 필수
현행 표는 열이 "순차형 / AI 생성 중심 / 가지"로 제품명이 없고, 본문 문장 "순차형 도구는 분기 구조 설계 기능이 제한적"은 Twine·Elementari가 있어 반박당한다.

**본문 문장 교정안(Ⅰ.4 첫 문단 대체)**
> 기존의 이야기 제작 도구는 장면을 순서대로 구성하는 순차형 제작 도구(예: Book Creator), 입력을 바탕으로 인공지능이 이야기·이미지를 생성하는 서비스(예: Gemini Storybook), 그리고 선택지에 따라 갈라지는 분기 서사 제작 도구(예: Twine, Elementari)로 나눌 수 있다. 분기 서사 도구는 이미 존재하나 하이퍼텍스트 문법이나 코드 블록 입력이 필요하고 영어 기반이어서 초등 저학년 창작 수업에는 문턱이 높으며, 계획 도구·인공지능 비계·교사 운영과 분리되어 있다. 국내 초등 현장에서 쓰이는 도구는 순차형이거나 인공지능 생성 중심이다. '가지'는 분기 설계의 문턱을 행동 버튼 연결과 '이야기 길 보기' 시각화로 낮추고, 준비도에 따라 분기를 잠그고 여는 3단계 비계 안에 계획(생각 나침반)·표현·인공지능 조력·학급 운영·출판을 하나의 창작 과정으로 통합하였다는 점에서 구별된다(표 1).

### ★ C. 생성형 AI 활용 근거 문단 삽입 (Ⅱ.5 「인공지능의 자리」 끝 또는 Ⅴ.4 제언 첫째 항) — 필수
> 생성형 인공지능 제공사인 Anthropic과 OpenAI는 미성년자가 이용하는 제품에 대해 API 활용을 금지하지 않고, 대신 운영자에게 연령 대응·콘텐츠 필터·모니터링·AI 사용 고지·아동 개인정보 보호법 준수를 요구한다(Anthropic 「Guidelines for Organizations Serving Minors」, OpenAI 「Under 18 API Guidance」). '가지'는 이 요건을 학교 상황에 맞게 구현하였다. 학생은 개인 계정 없이 교사가 등록한 학급 코드로 참여하고(연령 대응), 모든 요청은 서버를 거치며 폭력·성적 표현 등 유해 유형을 전송 전에 차단하고(필터), 기능별 교사 토글·사용량 상한·사용 기록(모니터링), AI 결과 배지와 대기 화면(고지), 작품 내용 외 개인정보 미전송과 보호자 동의 절차(개인정보 보호)를 갖추었다. 두 제공사 모두 API로 전송된 자료를 모델 학습에 쓰지 않으며 산출물의 권리는 이용자에게 귀속된다.

참고문헌에 추가(바탕체 14pt, APA):
- Anthropic. (2025). *Responsible use of Anthropic's models: Guidelines for organizations serving minors*. https://support.claude.com/en/articles/9307344
- Anthropic. (2025). *Usage policy*. https://www.anthropic.com/legal/aup
- OpenAI. (2025). *Under 18 API guidance*. https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance
- OpenAI. (2025). *Your data (API)*. https://developers.openai.com/api/docs/guides/your-data

정직한 한계(Ⅴ.3 한계에 한 줄 추가 가능): "제공사가 권고하는 아동 안전 시스템 프롬프트 문구를 그대로 적용하지는 않았고 자체 어린이 지시문을 쓰며, 교사에게 실시간 알림은 없고 사후 기록 확인 방식이다."

### D. 보호자 동의서 언급 (Ⅲ.1 적용 개요 또는 Ⅱ.6 교사 운영) — 권장, 두 문장

## 6. 예상 질문에 대한 답

- **"왜 붙임4를 통째로 바꾸나?"** 컨설팅 지적 ①의 해결책이 사이트 버튼이고, 옛 안내의 비밀번호가 더는 유효하지 않기 때문.
- **"등급 예상은?"** 개발 세션 판단: 2등급 기본, 1등급 열에 두셋. 결과 검증(사전·사후, 산출물 변화)이 등급을 가장 크게 움직임. 보고서에 이미 있는 수치를 앞으로 당겨 잘 보이게 하는 편집이 남은 최선.
- **"인포그래픽 글꼴은 고딕인데?"** 웹(심사 페이지)용은 고딕, 보고서용 PNG는 명조로 따로 만들었다. 보고서에는 `_폭170mm용.png`만 쓴다.
