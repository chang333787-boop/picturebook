# 학급 책장 + 댓글 설계 (SHELF-1 / COMMENT-1, 2026-07-11)

목적: "서로 읽는 문화" — 학급 작품을 책장처럼 모아 번갈아 읽고, 교사가 허락한 사람만 댓글을 남긴다.
목업(확정 시안) = mockups/shelf-comment-mockup.html (①입장 ②책장 ③작품+댓글패널 ④교사설정).

## 0. 확정 결정 (2026-07-11 대화)
- 책장 진입 = **기존 클래스 코드 재사용**(신규 코드 없음). 입장 화면에서 코드만 입력 → 책장(팀 이름 입력 제거).
- 댓글 = **별도 댓글 코드**(교사 생성/변경, 변경 시 이전 코드 즉시 무효). **⚠️07-11 수정: 코드는 "쓰기"에만 필요 —
  읽기는 작품을 볼 수 있으면 누구나**(불량 댓글은 교사 삭제+코드 교체로 통제). 클래스 코드를 댓글에 안 쓰는 이유 =
  작업 입장까지 열리는 코드라 외부(학부모) 배포 불가.
- 댓글 폼 = 이름(≤12자) + 내용(≤200자) + **댓글 코드 칸**("선생님에게 받을 수 있어요") — 최초 요청 형태 그대로.
  코드는 기기 세션에 기억(연속 댓글 시 재입력 불필요).
- 상단 크롬 = [📚 우리 반 책장][💬 댓글 N] ··· [⛶][✕]. **책장 버튼은 책장 컨텍스트(코드 세션) 있을 때만 노출**.
  엔딩에는 아무것도 안 얹음("다음 책 읽기" 기각 — 책장에서 직접 고름). 정렬 UI 없음(나열만, "댓글 적은 순" 기각).
- 팀 이름 = 만든 그대로 표시(자동 접미사 없음). 실명 팀명 학급 존재 → **책장 링크 공개 토글 기본 OFF**(클래스 코드 필요),
  켜면 링크/QR 하나로 학부모 공개.
- 책장 레이아웃 = 반응형 그리드(minmax ~150px·기기 폭 따라 3~6권/줄) + **max-width ~980px 가운데 정렬**(넓은 화면 가구 느낌)
  + 선반 바. 표지는 CSS 미니 표지(테마색+제목+한줄소개+💬N 배지), 이미지 생성 없음.

## 1. 뷰어 구조 (상태 3단)
```
[입장(코드)] → [책장] ↔ [작품] (같은 viewer.html 안 상태 전환·history 안 꼬임)
[개별 링크/QR] ────────→ [작품]  (책장 안 거침·책장 버튼 미노출)
[maker 다듬기/감상테스트] → 기존 그대로(책장 무관)
```
- 책장 데이터 = 팀별 표지 메타만(제목·한줄·테마·isPublic·댓글수) — 장면은 열 때만 로드(부하 0 설계).
- 복귀 = 상태 전환(오늘 RETURN-NOCLOSE와 같은 원칙: 창 닫힘/history 꼬임 금지).

## 2. 데이터/보안 (B안 = 서버 검증, 확정)
- `classes/{cid}/settings/shelfPublic` = true|false(기본 false), `commentEnabled`, `commentCode`(4~6자) — 기존 settings rules(teacher write) 재사용.
- 댓글 저장: `classes/{cid}/teams/{teamEnc}/comments/{pushId}` = { name(≤12), text(≤200), at }.
  rules(07-11 수정): **read = 작품 보기와 동일 게이트**(isPublic ∥ active member ∥ 담당교사 ∥ super_admin — scenes 패턴 미러),
  write = false(클라 직접 쓰기 금지). 쓰기는 **callable 1개**:
  - `postWorkComment({classId, team, code, name, text})` — 코드 검증·길이 제한·**팀당 일일 상한**(예: 30)·기록
  (읽기 callable은 폐기 — 직접 read라 배지 카운트·실시간도 공짜. 서버 검증은 쓰기에만: 속도 제한·금칙어 필터 확장 지점)
- 책장 목록 read: 후보 (a) 팀별 shelf 메타 인덱스 노드(classes/{cid}/shelf/{team}, 저장 시 갱신) (b) callable getClassShelf.
  구현 시 결정(관건=학생 클라가 팀 목록을 나열할 기존 권한 유무 — membership-login의 팀 목록 경로 확인).
- 클래스 코드→classId 해석 = 기존 classCodes/{code} 경로 재사용.

## 3. 교사 관리(관리화면 패널 1개 추가 — 목업 ④)
기존 AI 설정/팀 계정 패널 줄에 "📚 책장 · 💬 댓글" 패널: 책장 링크 공개 토글 / 댓글 ON·OFF /
댓글 코드 표시·변경 / (팀 카드에) 댓글 보기·개별 삭제. 마스터(super_admin)도 동일 조작 가능(기존 rules 동급).

## 4. 구현 순서(안) — 한 번에 한 단계
P1 책장(읽기 전용: 입장 개편+책장 상태+표지 그리드+작품 진입/복귀) → P2 댓글(callable 2개+패널 UI+교사 설정 패널)
→ P3 마감(댓글수 배지·shelfPublic 링크 모드·팀카드 댓글 관리·실기기). 규모: 표준~안전(functions·rules 포함) 1~2일급.
구현 시작 = 사용자 한도 리셋(7/12) 후 권장. 잔여 결정: 책장 목록 read 방식(a/b) — 구현 착수 시 코드 확인 후.
