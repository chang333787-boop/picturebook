## 1. 배경 · 목표
- 대상: 저학년 학생(태블릿·저문해·한국어) + 교사(PC/관리모드). 현재 도움말은 `showHelp()` **alert 1개**(ui.js:993)뿐 —
  시각화 0·저학년 부적합.
- 목표: (a) 학생이 **처음 켰을 때 헤매지 않게** 큰 흐름을 한 번 보여주고, (b) 언제든 다시 볼 수 있게 하며,
  (c) 교사가 **종이로 뽑아 배부**할 수 있는 1장짜리 설명서(학생·교사)를 제공.
- 비목표(이번): 인터랙티브 코치마크(버튼 하이라이트 투어)·TTS·다국어·영상. (후속 후보로만 기록)

## 3. S1 — 재열람 도움말 (콘텐츠 원본)
- **진입**: 기존 `btn-help`(showHelp) 업그레이드. 에디터 HUD·감상 화면·입장 화면에 ❓ 노출.
- **형태**: Warm Paper 오버레이(나침반 게이트 스타일 재사용) + **주제 탭/목록**. 각 주제 = 아이콘 + 1~2문장 + 그림.
- **주제(범위=학생 전체)**:
  1. 🚪 **들어가기** — 클래스 코드·모둠 이름·비밀번호(PIN)
  2. 🎨 **작품 고르기** — 텍스트/그림책/무비/체험 4종
  3. 🧭 **생각 나침반**(신규작품) — 쓰기 전 짧게 생각 정리
  4. ➕ **장면 만들기** — 글 쓰기·그림 그리기/올리기
  5. 🔗 **갈래 잇기** — 선택지(행동버튼)로 다음 장면 연결
  6. 💾 **저장** — 자동 저장(따로 안 눌러도 됨)
  7. 👀 **감상하기** — 완성한 이야기 읽기·선택하며 진행
  8. ✨ **AI 도움받기** — 글 다듬기·그림 완성(선생님이 켜준 반만)
- **저장 상태**: 없음(순수 표시). 열고 닫기만.

## 4. S2 — 최초 환영 모달
- **트리거**: 학생이 **에디터에 처음 도달**(입장+유형선택 후)한 시점. 기기 최초 1회.
- **"1회" 범위 결정(D-01)**: **기기 단위**(localStorage) 권장 — "앱 사용법"이라 작품/팀과 무관. 공용 태블릿은
  첫 학생만 보지만, ❓도움말이 항상 있어 나머지도 커버. (대안=팀 단위 DB 플래그. §8 참조)
- **키**: `localStorage['tutorial_v1_seen_' + branch_device_id]`(state.js:74 branch_device_id 재사용).
- **내용**: 짧은 3~5장 슬라이드 = "무엇을 하는 앱인가 + 큰 흐름(들어가기→만들기→감상)". 상세는 S1로 위임.
  마지막 장에 "❓를 누르면 언제든 다시 볼 수 있어요" 안내.
- **버튼**: [다음]/[이전]·[건너뛰기]·마지막 [시작하기]. dot progress.
- **나침반 게이트와 순서(D-02)**: S2 환영 모달을 **나침반 게이트보다 먼저**(신규작품이면 환영→닫힘→나침반 게이트).
  둘 다 오버레이라 스택 금지 — S2 dismiss 후 게이트 활성.
- **재사용**: ThoughtCompassGate.js 오버레이 카드 패턴(thought-compass-gate.js:20-65) 스타일 복제.

## 5. P1 — 학생용 사용설명서 (인쇄·A4 1장)
- **진입**: admin 패널에 [🖨 사용설명서(학생)] 버튼(입장카드 인쇄 옆).
- **내용(그림 위주·큰 글씨·번호 스텝)**: ①들어가기(코드/모둠/PIN 빈칸 표시) ②작품 고르기 ③장면 만들기(글·그림)
  ④갈래 잇기 ⑤저장은 자동 ⑥감상. 저학년이 책상에 두고 보는 **빠른 시작 1장**.
- **정적 콘텐츠**(팀 데이터 없음) → 자체 완결 인쇄 모듈.
- **재사용**: `_printEntryCards`(adminConsole.js:936) 인쇄 게이트 패턴 그대로 —
  `body.tutorial-print-student` + `#tutorial-print-root` + 주입 `@media print` + afterprint 정리.

## 9. 구현 순서 (Phase·전부 client-only 지향)
- **Phase A — S1 도움말(콘텐츠 원본)**: `tutorial-content.js` + showHelp 업그레이드(주제 모달). 최저위험·즉시가치.
- **Phase B — S2 환영 모달**: device 플래그 + 슬라이드 + 나침반 게이트 순서 처리. A의 콘텐츠 재사용.
- **Phase C — P1 학생 인쇄**: 인쇄 게이트 복제 + A 콘텐츠 압축.
- **Phase D — P2 교사 인쇄**: 동일 게이트 + 교사 체크리스트.
- 각 Phase: 하니스(모달 표시/1회/닫기·인쇄 root/게이트/afterprint) + 실환경 스모크 + commit 전 보고.
