# 쓰기 후 활동 흐름 구조 정리 — 3구역 그룹핑 (WRITE-AFTER-FLOW-GROUPING-UX, 2026-06-30)

> 정본 철학: **쓰기 후 활동은 AI가 대신 고쳐주는 기능이 아니라, AI가 질문하고 검사해서 학생이 직접 고친 뒤, 마지막에 AI 장면발전과 AI 그림책 마감을 후보로 비교하는 마무리 활동이다.**

## 왜 순서형 → 자료 묶음형으로 바꿨나
- 기존: 생각 점검 질문 → 작품 검사 → 직접 고치기 → AI 장면발전 → AI 그림책 마감 (선형 나열).
- 문제: **생각 점검 질문 다음에 작품 검사가 순서처럼** 보여, 둘이 겹치거나 "둘 중 하나만" 하는 느낌.
- 실제 관계: 생각 점검 질문과 작품 검사는 **합치는 게 아니라 둘 다 고쳐쓰기 전에 참고하는 자료**(동등). 그래서 **목적별 3구역**으로 묶어 "순서 강제" 인상을 없앴다.

## 3구역 구조 (viewer-ai.js `_showModeModal`)
| 구역 | 제목 | 설명 | 카드 |
|---|---|---|---|
| 1 | **1. 고쳐쓰기 자료 보기** | AI가 질문과 점검 결과를 보여줘요. 글은 내가 직접 고쳐요. (두 가지 모두 참고 자료예요.) | 생각 점검 질문 · 작품 검사 (동등) |
| 2 | **2. 직접 고치기** | 질문과 검사 결과를 보고 장면을 직접 고쳐요. | 직접 고치기(안내 카드) |
| 3 | **3. 마지막 다듬기** | 고친 뒤에 AI가 만든 후보를 비교해 볼 수 있어요. | AI 장면발전 · AI 그림책 마감(교사·그림책만) |

- "먼저/다음/마지막" 뉘앙스는 **구역 제목(1·2·3)에만**. 1구역 안 두 카드는 동등(순서 강제 없음).

## 카드 문구 (학생용 명확화)
- 생각 점검 질문 — "내 이야기를 더 깊게 돌아볼 질문을 받아요. AI가 대신 고치지 않고 질문만 해요."
- 작품 검사 — "맞춤법, 장면 연결, 인물 이름처럼 확인할 점을 찾아요. AI가 대신 고치지 않고 알려줘요."
- 직접 고치기 — "AI가 알려준 내용을 보고 내가 직접 장면을 고쳐요. 결과의 ‘장면으로 이동’을 누르면 그 장면으로 가요. 내가 고친 글이 최종 작품이 돼요."
- AI 장면발전 — "고친 글을 바탕으로 더 자연스러운 표현 후보를 받아요. 사건·선택지·엔딩은 그대로 두고 표현만 발전시켜요."
- AI 그림책 마감 — "그림책 그림을 더 완성된 느낌으로 다듬어요. 원본은 그대로 두고 결과를 비교한 뒤 선택해요. (교사용 · 외부 AI 전송 가능)"
- 문구 원칙: "AI가 고쳐줘요" 금지, "AI는 질문/점검/후보를 보여줌 · 학생이 직접 고침" 강조.
