## 작품 검사 역할
- 기존 `callWorkCheck` 기능은 그대로. 결과 화면을 **학생용 "고쳐쓰기 점검표"**로 정리(진단서/교사용 느낌 완화).
- AI는 확인할 점을 찾아줄 뿐, **글은 학생이 직접 고친다**. 결과 항목 → `이 장면 고치기`(Phase 5 흐름)로 연결.

## 생각 점검 질문과의 차이 (결과 상단 안내에 명시)
- 생각 점검 질문 = 더 생각할 질문. 작품 검사 = 고쳐 볼 부분 찾기. "생각 점검 질문은 더 생각할 질문을, 작품 검사는 고쳐 볼 부분을 찾아줘요."

## 변경한 문구/라벨 (viewer-ai.js — 표시만, schema key 무변경)
- 모달 제목: `🔍 작품 검사 결과` → **`🔍 작품 검사 — 고쳐 볼 점`**
- 상단 안내(학생용·`.ai-check-intro--student`): "AI가 작품에서 **확인할 점**을 찾아줬어요. 글은 **내가 직접** 고쳐요. 아래에서 고쳐 볼 장면을 골라 **‘이 장면 고치기’**를 눌러요." + 차이/복귀 안내 한 줄.
- 카테고리 라벨(내부 key `spelling/coherence/character/branchFlow` 유지):
  - `맞춤법` → **글자와 문장 확인**
  - `장면 간 유기성` → **장면 연결 확인**
  - `캐릭터 일관성` → **인물과 이름 확인**
  - `분기 흐름` → **선택지·마무리 확인**
- 항목 본문: **`확인할 점: …`** 라벨 + 장면 라벨 강조. (완성문 제시 아님 — 확인 대상만.)
- 빈 카테고리: `문제 없음 ✓` → **`확인할 점 없어요 ✓`**
- 전 카테고리 0: "크게 고칠 부분이 많지 않아요. 그래도 한 번 더 읽으며 선택지와 마무리를 확인해 보세요." 안내.
- 결과 없음 alert: **"아직 작품 검사 결과가 없어요. ‘작품 검사’를 눌러 확인할 점을 받아 보세요."**
- 금지 문구(오류/틀렸습니다/정답/자동 수정/AI가 고쳐줍니다) 미사용.
