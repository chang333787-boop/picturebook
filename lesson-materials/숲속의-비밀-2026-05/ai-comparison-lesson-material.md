## 0. 수업 흐름 안내

이 자료는 **공개수업 / 수업 시연용**입니다.

핵심 질문:
1. 무엇이 가장 멋져 보이는가?
2. 무엇이 가장 우리 작품 같은가?
3. AI가 더 잘한 점은 무엇인가?
4. AI가 바꾸면서 사라진 점은 무엇인가?
5. AI에게 맡겨도 되는 것은 무엇인가?
6. AI가 바꾸면 안 되는 작품의 핵심은 무엇인가?

학생 활동:
- 원본 / AI 1단계(살짝 다듬기) / AI 2단계(장면 발전) 세 가지를 비교

- AI에게 맡겨도 되는 것과 바꾸면 안 되는 것 정리

## 3. 외부 AI 도구로 이미지 박는 방법

### 추천 워크플로우 (가장 단순)

1. **ChatGPT Plus (DALL-E 3 inpaint)** 사용
2. 원본 이미지 1장 업로드
3. 메시지: "이 그림을 새로 그리지 말고, 선과 색만 살짝 정돈해주세요." + 위 1단계 프롬프트 박음
4. 결과가 너무 다르면 다시 박음 (보통 1~3회 시도)
5. 다운로드 → `scene_{번호}_ai_level1.png` 박은 이름으로 같은 폴더 박음
6. 2단계도 같은 방식 + 2단계 프롬프트 박음

### 도구별 특징

| 도구 | 1단계 (정돈) | 2단계 (발전) | 캐릭터 일관성 |
|---|---|---|---|
| **ChatGPT (DALL-E 3)** | edit 모드 + 원본 업로드 + 프롬프트 | 동일 + 묘사 박음 | 약함 — 21장 박을 때 캐릭터 박지 X 박힐 수도 |
| **Google Imagen / Gemini** | Imagen 3 edit + mask | + style reference (첫 장면을 reference로) | 중간 — style reference 박은 거 박은 게 강력 |
| **Midjourney** | `/imagine` + image URL + `--iw 2` | + `--sref` (캐릭터 시드) | 중간 — 손그림 느낌 박지 X (일러스트로 박을 가능성) |
| **Stable Diffusion (SDXL img2img)** | denoising 0.3~0.4 | denoising 0.5~0.6 + ControlNet (canny) | 강함 — 박지만 기술 박은 사람 박을 거 |

### 수업 사용 권장

**5~6장만 박으세요** (1, 2, 5, 10, 17, 19 추천 — 도입·중반·해피·진엔딩 박힘). 21장 모두 박지 X — 시간 박을 거 박은 거 박지 X 박음.

## 4. 정리 — 우리가 정해야 할 것

### 🤝 AI에게 맡겨도 되는 것
- 맞춤법 오타 ("쫒기고" → "쫓기고", "맷돼지" → "멧돼지", "쓰려졌다" → "쓰러졌다")
- 띄어쓰기 ("두명" → "두 명", "가야한다" → "가야 한다")
- 같은 단어를 두 번 박은 어색한 문장
- "마루하루" 같은 붙은 이름을 분리
- 그림의 흐릿한 부분을 살짝 또렷하게
- 색칠이 삐져나간 부분을 정돈

### 🚫 AI가 바꾸면 안 되는 것
- 장면의 개수와 분기 순서 (21장 그대로)
- 선택지의 의미와 다음 장면 연결 (nextId)
- 엔딩의 방향 (행복/슬픔/진엔딩)
- 캐릭터의 모습과 정체성 (마루·하루·토토·모찌·뇨뇨·몽실이·무진)
- "시민", "막대자", "뇨뇨" 같은 우리만의 단어
- 그림의 구도와 배치
- 학생 손그림의 따뜻한 느낌

### 💜 우리 작품의 핵심
- 마루·하루의 모험 이야기
- 친구를 만나고 도와주는 마음
- 9개의 다양한 엔딩 — 우리가 만든 선택의 결과
- 장면 19 박힌 "착해진 밀렵꾼" 진엔딩의 의미
- 학용품(막대자·필통)으로 싸우는 코믹함
- 친구들의 모습은 우리가 정한다

## 5. 수업 진행 도움말 (교사용)

### 권장 흐름 (40분 기준)

1. **(5분) 도입** — "AI는 작품을 더 보기 좋게 도울 수 있지만, 작품의 중심은 사람이 정합니다." 박은 핵심 메시지 박음

3. **(10분) 그림 비교** — 외부 도구 박은 거 박지 X 박혔으면 프롬프트 카드만 박음. 박혔으면 원본 ↔ AI 비교
4. **(7분) 정리** — "AI에게 맡겨도 되는 것 / 바꾸면 안 되는 것" 학생 발표
5. **(3분) 마무리** — "우리 작품의 중심은 우리가 정한다" 박은 다짐

### 주의
- **AI가 무조건 더 좋다는 인상 박지 X 박음** — 비교만
