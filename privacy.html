가지(branch) 개인정보 처리방침

시행일: 2026-06-10 · 최종 수정일: 2026-07-23
가지는 학생들이 직접 만든 이야기와 그림을 소중히 다루는 수업용 도구입니다. 이 개인정보 처리방침은 가지가 어떤 정보를 왜 사용하는지, 학생 작품과 계정 정보를 어떻게 보호하는지 알기 쉽게 설명하기 위해 마련되었습니다.

1 어떤 목적으로 사용하나요

가지는 수업을 돕기 위해 꼭 필요한 범위에서만 정보를 사용합니다.

  • 학생이 만든 작품을 만들고, 저장하고, 감상할 수 있도록
  • 교사가 학급과 팀을 관리할 수 있도록
  • 수업을 원활하게 운영하기 위해
  • 선택한 경우 AI 글 다듬기 등 기능을 제공하기 위해
  • 오류에 대응하고 안전하게 운영하기 위해

2 어떤 정보를 사용하나요

교사·관리자

  • 이메일 주소
  • Google 계정으로 로그인하는 경우: Google 계정 이메일, 표시 이름, 프로필 사진 URL
  • Firebase Authentication UID(로그인 식별값)
  • 계정 생성일, 마지막 로그인 시각, 인증 제공자 정보
  • 학급 ID, 학급 설정, AI 사용 설정

학생·팀

  • 팀명 또는 학생 계정명
  • 교사가 정한 팀 표시 이름(닉네임) — 학급 책장 등에서 로그인 아이디 대신 보이는 이름(교사 선택, 없으면 표시 안 함)
  • PIN 또는 비밀번호
  • 학급 ID
  • 작품 데이터(장면 본문, 선택지와 분기 구조 등)
  • 업로드한 이미지 또는 그림판으로 그린 이미지
  • 작품 설정, 저장·수정 시각
  • 작품 댓글: 작성 시 입력한 이름(별칭 가능)과 댓글 내용, 작성 시각 — 해당 작품을 볼 수 있는 사람에게 표시되며, 댓글 작성은 교사가 나눠준 댓글 코드가 있어야 가능하고 담당 교사가 언제든 삭제할 수 있습니다
학생은 원칙적으로 Google 계정 로그인을 사용하지 않으며, 교사가 안내한 팀명과 PIN 또는 비밀번호 방식으로 접속합니다. 학생의 실명 입력은 필수로 요구하지 않습니다.
작품 공개·링크 공유 — 교사는 학생 작품을 공개로 설정하거나 학급 책장을 열 수 있습니다. 이때 해당 작품·책장은 교사가 공유한 링크가 있으면 로그인 없이 누구나 볼 수 있으며, 공개된 작품에는 학생이 만든 작품 내용·팀 표시 이름이 함께 보일 수 있습니다. 공개 여부는 교사가 정하고 언제든 다시 비공개로 되돌릴 수 있습니다.

자동으로 모이는 기술 정보

  • 접속 기록, 브라우저·기기 정보, 오류 로그
  • 로그인 시각, 인증 제공자, 인증 오류 기록
  • 브라우저에 잠시 저장되는 편집 상태, 보기 설정, 임시 세션 정보(localStorage·sessionStorage)

3 얼마나 보관하나요

개인정보와 작품 데이터는 학급 운영 기간 동안 보관하며, 학급 운영이 끝난 뒤 1년 이내 또는 교사·운영자의 삭제 요청 시 지체 없이 삭제합니다.

다만 보안, 장애 대응, 분쟁 처리, 관련 법령 준수를 위해 필요한 로그와 백업 정보는 필요한 기간 동안 보관될 수 있습니다.

연구·포트폴리오·전시처럼 위 기간을 넘겨 학생 작품을 계속 보관하려는 경우에는, 별도의 동의가 필요할 수 있습니다.

4 다른 곳에 제공하나요

가지는 이용자의 개인정보를 원칙적으로 제3자에게 제공하지 않습니다. 다만 법령에 근거가 있거나 적법한 절차에 따른 요청이 있는 경우에는 예외가 될 수 있습니다.

5 어떤 외부 서비스를 이용하나요

가지는 안정적인 운영을 위해 아래 외부 서비스를 이용합니다.

  • Google Firebase — Authentication(로그인), Realtime Database(데이터 저장), Cloud Storage(파일 저장), Cloud Functions(서버 처리), Hosting 등 인프라
  • GitHub Pages 등 정적 호스팅(서비스 주소: branchstory.co.kr) — 페이지 제공
  • Anthropic API — AI 텍스트 기능(글 다듬기·생각 점검 질문·작품 검사) 제공
  • OpenAI API — AI 이미지 기능(그림책 마감 변환, 교사가 학급에서 켠 경우에만) 제공

6 AI 기능과 개인정보

AI 기능은 선택적으로 사용하는 기능이며, 교사가 학급 설정에서 켠 기능만 사용할 수 있습니다. AI 텍스트 기능을 사용할 때에는 작품 본문, 장면 정보, 선택지 등 기능 수행에 필요한 정보가 Anthropic API로 전송될 수 있습니다. AI 이미지 기능을 사용할 때에는 업로드 이미지 또는 그림판 이미지가 OpenAI API로 전송될 수 있습니다.

AI 기능을 사용하지 않으면 해당 작품 내용이나 이미지는 AI API로 전송되지 않습니다.

AI가 만든 결과는 원본 작품을 자동으로 덮어쓰지 않고, 사용자가 확인할 수 있는 후보로 제공하는 것을 원칙으로 합니다. 특히 이미지 AI 결과는 원본 이미지 데이터를 바로 덮어쓰지 않는 구조를 원칙으로 합니다.

안전하게 쓰기 위한 장치 — 2026-09-06 보완

  • 교사 감독: AI 기능은 항목별로 교사가 켠 것만 동작하며 기본값은 꺼짐입니다. 교사는 학급 전체 AI를 즉시 중지할 수 있습니다.
  • 학생 직접 접속 없음: 학생은 AI 서비스에 접속하거나 계정을 만들지 않습니다. 모든 요청은 서버를 거치며, 학생 이름·학년 등 개인정보는 AI로 전송하지 않습니다.
  • 유해 표현 차단: 폭력·잔혹, 성적 표현, 욕설, 괴롭힘·혐오, 자해, 개인정보 노출 등의 유형은 서버가 먼저 걸러 AI에 보내지 않고, AI 결과도 같은 기준으로 다시 확인합니다.
  • 원본 보존: AI 결과는 원본과 분리 저장된 후보이며, 학생·교사가 비교해 고릅니다.
  • 사용량 상한: 모둠별 횟수 상한과 학급·서비스 전체의 일일 상한이 있으며, 교사는 모둠별 사용 기록을 볼 수 있습니다.
Anthropic·OpenAI API로 전송되는 데이터는 각 회사의 API 데이터 처리 정책에 따라 처리됩니다. 두 회사 모두 API 입력 및 출력을 기본적으로 모델 학습에 사용하지 않는다고 안내하고 있으나, 구체적인 보관 기간과 처리 방식은 각 회사의 정책 및 서비스 설정에 따릅니다.

7 이용자의 권리

  • 이용자는 언제든지 자신의 개인정보에 대해 열람, 정정, 삭제를 요청할 수 있습니다.
  • 학생의 정보는 보호자 또는 담당 교사를 통해 요청할 수 있습니다.
  • 요청은 아래 문의 이메일로 보내주시면 지체 없이 처리합니다.

8 정보는 어떻게 삭제되나요

  • 삭제 요청이 있거나 보유 기간이 지나면 해당 정보를 삭제합니다.
  • 전자적으로 저장된 파일은 복구하기 어려운 방식으로 삭제합니다.
  • 백업과 로그는 필요한 기간이 지난 뒤 순차적으로 삭제합니다.

9 안전하게 지키기 위한 노력

  • Firebase Authentication을 통한 로그인 보호
  • 권한에 따른 접근 제한(교사·학급 단위 분리)
  • Firebase 보안 규칙 적용
  • 전송 구간 암호화(HTTPS)
  • AI 연동에 쓰는 API 키는 서버에서 안전하게 보관
  • 학생의 원본 작품을 보호하는 구조

10 쿠키와 브라우저 저장소

가지는 편리한 이용을 위해 브라우저에 일부 정보를 저장할 수 있습니다.

  • 로그인 유지
  • 임시 편집 상태
  • 보기 설정
  • 이전 작업으로 돌아오기

이 정보는 브라우저 설정에서 삭제할 수 있습니다. 다만 일부 기능 이용이 제한될 수 있습니다.
